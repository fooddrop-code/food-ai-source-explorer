# 식품 원재료 정보 탐색기

식품 R&D 조사 단계에서 원재료의 공식 정보와 사용 조건을 빠르게 확인하기 위한 웹 도구입니다.

## 해결하려는 문제

식품 원재료를 조사할 때 정보의 출처와 사용 조건을 빠르게 확인하기 어렵습니다.

## 주요 기능

- 원재료명 검색
- 식품의약품안전처 식품 원재료 정보 API 연동
- 원재료명, 이명, 분류, 영문명, 사용 부위, 사용 조건 표시
- 공식 데이터 출처와 조회 시각 표시
- 검색 결과 없음 및 서버 오류 안내
- 검색 결과 페이지 이동
- 원료명 복사, 초기화, 빠른 검색 기능

## 기술 구성

- HTML / CSS / JavaScript
- Node.js / Express
- 공공데이터포털 식품의약품안전처 식품 원재료 정보 API
- Git / GitHub

## 실행 방법

1. `food-ai-source-explorer/server` 폴더에서 `npm.cmd start` 실행
2. `food-ai-source-explorer/app/index.html`을 브라우저에서 열기
3. 원재료명을 입력하거나 빠른 검색 버튼으로 검색

## 데이터 출처

- 식품의약품안전처 식품 원재료 정보 API
- 공공데이터포털

## 한계점

- 검색 결과는 공식 원재료 정보 확인을 돕기 위한 자료입니다.
- 실제 제품 적용 가능 여부는 관련 법령, 제품 유형, 배합 조건 및 전문가 검토가 필요합니다.
- 현재 버전은 원재료 정보 탐색 기능에 집중한 MVP입니다.

## 향후 계획

다음 프로젝트에서는 공식 영양성분 데이터를 분석해 제품군 비교, 유사 제품 탐색, 식품공학적 해석까지 확장할 예정입니다.
