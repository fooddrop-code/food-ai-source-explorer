# 식품 원재료·제품 정보 탐색기

> 공식 출처를 근거로 식품 원재료와 건강기능식품 제품 정보를 탐색하고, 쉬운 언어의 요약과 원문 출처를 함께 제공하는 웹 도구

## 문제

소비자와 식품 콘텐츠 제작자는 식품 원재료 또는 제품의 정보를 확인할 때 여러 출처를 오가야 하며, 검색 결과가 어떤 근거에 기반했는지 확인하기 어렵다.

## 첫 번째 사용자

국내 식품 정보를 조사해 콘텐츠나 구매 판단의 참고자료를 만드는 사용자.

## MVP

사용자가 원재료명 또는 건강기능식품 제품명을 입력하면 다음을 제공한다.

1. 공식 데이터에서 찾은 일치 항목
2. 원문 데이터에 근거한 핵심 항목 요약
3. 데이터 제공기관, 원문 링크 또는 API 식별 정보, 조회일
4. 항목을 찾지 못했을 때의 명확한 안내

## 이번 단계에서 하지 않는 것

- 질병의 진단·치료·예방 조언
- 개인별 섭취량 또는 안전성 판단
- 공식 데이터에 없는 사실의 단정
- 사용자 건강정보의 저장

## 성공 기준

- 준비한 평가 사례 30건에서 공식 데이터의 식별 정보와 검색 결과가 일치한다.
- 표시된 요약의 각 사실을 원문 필드 또는 출처로 추적할 수 있다.
- 데이터에 없는 정보는 추정으로 채우지 않고 `확인되지 않음`으로 표시한다.
