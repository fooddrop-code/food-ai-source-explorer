# 수동 테스트 기록

## 테스트 환경

- 실행 방법: `server` 폴더에서 `npm.cmd start`
- 화면: `app/index.html`
- 데이터 출처: 식품의약품안전처 식품 원재료 정보 API

## 확인 항목

- [ ] `대두` 검색 시 원재료 정보 카드가 표시된다.
- [ ] 원재료명, 이명, 분류, 영문명, 사용 부위, 사용 조건이 표시된다.
- [ ] 데이터 출처와 조회 시각이 표시된다.
- [ ] 존재하지 않는 검색어에서 검색 결과 없음 안내가 표시된다.
- [ ] 다음 10건 보기와 이전 10건 보기로 결과 페이지를 이동할 수 있다.
- [ ] 원료명 복사 버튼을 누르면 원료명이 클립보드에 복사된다.
- [ ] 초기화 버튼을 누르면 검색어와 결과가 초기 상태로 돌아간다.
- [ ] 빠른 검색 버튼으로 원료명 검색을 시작할 수 있다.
- [ ] 서버가 꺼진 상태에서 오류 안내가 표시된다.
