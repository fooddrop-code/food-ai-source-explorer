# 초기 검색 평가 계획

## 목적

원재료 탐색기가 공식 데이터에 없는 정보를 생성하지 않고, 검색어 변형에도 근거가 있는 결과를 제공하는지 확인한다.

## 초기 사례

`evals/cases-template.csv`에 10개 사례를 기록했다. 이 중 001~004는 공공데이터포털의 식품 원재료 정보 API 안내에서 예시로 확인한 `Abiu` 레코드를 사용한다.

## 판정 기준

| 항목 | 통과 조건 |
| --- | --- |
| 출처 | 결과마다 제공기관·조회일·원문 필드를 표시한다. |
| 검색 | 대표명·이명·영문명·학명 검색이 기대 결과와 일치한다. |
| 무결과 | 데이터에 없는 항목에 대해 추정 답변을 하지 않는다. |
| 입력 | 빈값과 앞뒤 공백을 일관되게 처리한다. |

## 현재 한계

- API 인증키를 아직 발급받지 않아 실제 응답으로 재현 검증하지 않았다.
- 010번 한글 표기는 공식 API 응답 확인 전까지 `검증 필요`로 유지한다.
- MVP 구현 전에는 이 사례를 최소 30건으로 늘린다.
