# 문제 정의와 범위

## 가설

식품 정보를 조사하는 사용자는 원재료·제품 정보의 출처를 빠르게 확인할 수 있다면, 검색 결과를 더 신뢰하고 자료 조사 시간을 줄일 것이다.

## 핵심 사용자 흐름

`검색어 입력 → 공식 데이터 검색 → 일치 후보 선택 → 근거가 포함된 결과 확인`

## 화면에 표시할 최소 정보

| 구분 | 원재료 | 건강기능식품 제품 |
| --- | --- | --- |
| 식별 정보 | 대표명, 이명, 영문명 | 제품명, 제조사, 품목제조관리번호 |
| 설명 | 분류, 사용 조건 등 원문 제공 범위 | 섭취 방법·기한 등 원문 제공 범위 |
| 근거 | 제공기관, 조회일, 원문 필드 | 제공기관, 조회일, 원문 필드 |

## 정확성 원칙

1. AI 요약은 검색된 공식 데이터 필드 안에서만 작성한다.
2. 검색 결과와 요약을 분리해 보여준다.
3. 추론, 해석, 의학적 판단은 첫 MVP에 포함하지 않는다.
4. 데이터가 없거나 모호하면 불확실성을 표시한다.

## 결정이 필요한 항목

- 첫 MVP가 원재료 검색부터 시작할지, 원재료와 건강기능식품 제품 검색을 함께 시작할지
- 주 사용자가 소비자인지 식품 콘텐츠 제작자인지
- API 인증키 발급 후 실제 API를 연결할 시점
