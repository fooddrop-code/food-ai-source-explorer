# 개발 버전 검증 기록

검증일: 2026-10-14

## 완료한 검증

- TypeScript 타입 검사 통과.
- 원재료 이름·E번호 중복 제거, 알려지지 않은 성분 처리, 유사 화합물의 오탐 방지 등 단위 검사 10개 통과.
- Expo 웹 번들 생성 통과.
- iOS·Android Hermes 코드 번들 생성 통과.
- 공개 데이터의 한국 판매 필터가 포함된 실검색 응답 확인.
- 브라우저에서 ‘오레오’ 검색 → 제품 선택 → 한국어 원재료 조회 → 레시틴 설명·평가 조건·출처 표시 확인.
- 실제 조회한 원재료 원문을 직접 입력해 분석 결과 확인.
- 보관함 저장 → 페이지 재접속 → 목록·상세 확인 → 삭제 확인.

## 한계와 미검증 사항

- 식품안전나라 문서와 샘플 응답을 확인했으나, 발급된 사용자 인증키의 실검색은 미검증.
- 설치 가능한 APK/AAB/IPA는 생성하지 않음.
- 실제 아이폰·안드로이드 기기의 화면·키보드·저장·네트워크 동작은 미검증.
- 상용 배포·스토어 심사·운영 환경·성분별 국내 최신 사용기준은 별도 검토 필요.
- npm 보안 감사에서 Expo 개발 도구 관련 간접 의존성 경고 22건(높음 15, 중간 7)이 남음. 경고의 제품 출시 영향과 상위 패키지 수정은 추후 확인해야 함.

이 기록은 검증된 범위만 적습니다. 코드 빌드 성공을 실제 기기 검증이나 제품 안전성 인증으로 해석하지 않습니다.
